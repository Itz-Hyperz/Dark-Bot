# Dark Bot

**The all-in-one, self-hosted Discord bot built for real communities.**

Dark Bot is a ground-up rewrite of the legendary **HypeBot**. Same ambition. Less bloat. Per-guild control. Built to run on *your* VPS, with *your* data, for as __many servers__ as you need.

> Multi-guild. Slash commands. Extensions. No shared-hosting gimmicks.

## Why Dark Bot

HypeBot ran in hundreds of communities and reached hundreds of thousands of users. It was powerful — and painful. A 500-line config. Single-guild thinking. Code that had grown too heavy.

**Dark Bot was written from scratch to fix that:**

- Config cut down from **~500 lines to ~40**
- **Per-guild settings** instead of one global dump
- Interactive menus instead of hunting through files
- Bloat stripped. Features kept. New systems added.

You own the instance. You own the database. You invite *your* bot.

## Requirements

Dark Bot is **not** a “paste token into shared bot hosting” product.

| Requirement | Notes |
|---|---|
| **VPS** | Dedicated / VPS. Shared bot hosting is not supported. |
| **Node.js** | `v16.13.2` |
| **MySQL** | Required for punishments, levels, giveaways, marriages, stickies, and more |
| **FFmpeg** | Required for music (install on Linux VMs) |
| **Discord application** | Your own bot account + invite generated by Dark Bot |

## Quick start (high level)

1. Provision a VPS and install Node.js **16.13.2** + MySQL.
2. Import the provided `install.sql` into a new database.
3. Fill out `config.js`.
4. Install dependencies and start the client:
   - **Windows:** run `CLIENT.bat` → install modules (`#2`) → start (`#1`)
   - **Linux:** `npm i` then `node .` (typically inside `screen`)
5. Use the **invite link the bot prints**. Do not invent your own OAuth URL.

## Extensions

Dark Bot 1.3+ loads **folder-based extensions**:

1. Include an `extension.json`
2. Drop the folder into `extensions/`
3. Configure
4. Restart the bot
